Connect a bot in hob

      
In that bot's Hermes profile config, set the MCP server agent_computer to URL http://<tailscale-ip>:9879/mcp with header Authorization: Bearer <that bot's token>. Then ask the bot to run computer_list — it should see one computer, Portal. Each bot's browser profile, files and shell stay inside its own folder and no bot can name another bot's profile. Full steps are in the README.
